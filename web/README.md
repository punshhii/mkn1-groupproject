# ПС-4 WEB (fw-web)

- **Язык:** PHP (Debian 12) + nginx (HTTPS)
- **Пользователь ОС:** fw-web
- **Требования:** FR-03, FR-30 – FR-38, FR-44
- **Команда:** Иванова, Мартыненко, Назмеева, Попов, Саитгареев (вместе с ПС-3)
- **Сокет:** `/run/fw/web.sock` (0600)

## Модули

| Модуль | Назначение |
|---|---|
| server | точка входа, маршрутизация, HTTPS на 8443 |
| auth | проверка сеанса, CSRF |
| pages | разделы меню (таблица 7, столбец Web) |
| api | вызовы ядра управления / подсистем |
| protocol | клиент Unix-сокета подсистем: JSON-конверт, тайм-аут 5 с, 2 повтора с тем же msg_id, M01–M16, M16 (как `common/fwcommon/protocol.py`) |

## Принимает

| Команда | Назначение | Источник |
|---|---|---|
| `—` | ПС-4 эквивалентна ПС-3 по интерфейсам (src = "web") | — |

## Отправляет

- те же команды, что у ПС-3, с src = "web"

## Тесты

```bash
php web/tests/test_protocol.php                       # без подсистем
PHP=/путь/к/php python3 tests/stand/test_php_client.py  # против заглушек mock_core
```

Пример вызова:

```php
require 'src/protocol.php';
try {
    $r = FwProtocol::request('/run/fw/authd.sock', 'web', 'authd', 'auth.login',
                             ['id' => $id, 'password' => $pwd, 'source' => 'web']);
    $sid = $r['payload']['session_id'];
} catch (FwProtocolError $e) {
    // $e->fwCode: M02, M12, M16 ...; $e->fwMessage — текст для области сообщений
}
```

## Правила

- Шапка каждого файла по шаблону (см. `CONTRIBUTING.md`).
- Данные от администратора и из сети проверяются на входе; данным другой подсистемы без проверки не доверяют.
- Ошибки возвращаются кодом и сообщением из `common/messages.json`; необработанные исключения не завершают процесс.
- Каждый модуль имеет unit-тесты; ПМИ своей подсистемы пишет её команда (`docs/pmi_template.md`).
